# Build a PDF Inspector 

A beginner-friendly course that teaches you how to build a PDF Inspector using Python, PyMuPDF, and Google Colab.

By the end of this course, you will build a tool that can:

-Count PDF Pages
-Read PDF Metadata
-Check If a PDF Is Encrypted
-Detect If a PDF Is Scanned
-Count Images in a PDF
-Display PDF Page Sizes
-Extract Additional PDF Information
